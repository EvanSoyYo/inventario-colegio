# Guion para video demostrativo

Duración sugerida: 90 a 120 segundos. Grabar la pantalla después de crear la cuenta administrativa y ejecutar las pruebas pendientes.

1. **Presentación (10 s):** “Esta aplicación administra recursos tecnológicos, préstamos y devoluciones de un colegio técnico profesional.”
2. **Panel (15 s):** mostrar conteos de disponibles, prestados, mantenimiento y vencidos.
3. **Equipo (20 s):** registrar un equipo ficticio y buscarlo por código.
4. **Préstamo (20 s):** crear préstamo válido y mostrar que el equipo aparece prestado.
5. **Validación (10 s):** intentar prestar nuevamente el mismo equipo y mostrar el rechazo.
6. **Devolución (15 s):** registrar la devolución y mostrar estado actualizado e historial.
7. **Cierre (10 s):** mostrar CSV y describir en una frase la arquitectura PHP/JSON y base de datos.

Mostrar solo datos ficticios. No grabar contraseñas ni información real. Si el módulo WebAssembly no se compila, explicar esa limitación con honestidad en la presentación.
